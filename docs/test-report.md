## 2. Key Fixes Implemented for This Release Candidate

1. **Backend-Owned Joint Batch Approval (`PUT /api/plans/{plan_id}/approval`):** Replaced client-side `crypto.randomUUID()` loops with deterministic backend `uuid5` item intents stored under `plan_approvals` & `plan_approval_items` (`SCHEMA_VERSION = 4`), preventing duplicate shipments on double-click, page reload, tick advancement, container restart, and concurrent requests.
2. **Stale & Running Provenance Integrity:** Separated `observed_at` (wall-clock backend observation time) from simulator `sim_time` and HTTP receipt time; introduced `RUNNING_COHERENT_GRACE_SECONDS` (`15.0 s`) with `X-Bup-{As-Of-Tick,Current-Tick,Age-Ticks,Observed-At,Cached,Degraded}` headers; enforced strict `503` read/batch-write blocking under `stale_data`.
3. **Clean-Core / Reproducible ML & Readiness Separation:** Locked `ml-service` wheels via [requirements.lock.txt](../ml-service/requirements.lock.txt), excluded local weights & `.joblib` artifacts from Git and images, automated `scripts/prepare-models.py` (download/verify + dataset collect + locked-container training + `--network=none` smoke), and updated `/health/ready` to require both models (`200` iff ready, else `503`).
4. **Curated Clean-Checkout Evidence Fallback:** Updated [evaluation.py](../backend/intelligence/evaluation.py) and [EvaluationHealth.tsx](../frontend/src/EvaluationHealth.tsx) to fall back to [evidence/](evidence/) cleanly when `artifacts/` is absent and surface `"not_yet_measured"` when unmeasured.
